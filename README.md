# THE GAZE 2

A clean starting point for THE GAZE.

This repository intentionally contains only the basic app scaffold. No previous UI, audio engine, modules, or architecture are carried forward.

## Development

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Project principles

- Build one small feature at a time.
- Verify each feature before adding another.
- Keep the interface and audio behavior simple and functional.
